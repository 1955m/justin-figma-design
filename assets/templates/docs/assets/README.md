# Common graphics

Shared guidance and user-provided drop-in assets for Figma work.

| Resource | Use |
|---|---|
| [`icons.md`](icons.md) | Approved icon sources, placement rules, and icon QA |
| [`avatars/`](avatars/) | User-provided placeholder avatars and import guidance |

Read the relevant guide before importing or drawing a graphic. Prefer
existing Figma instances and approved library assets over redraws.

Do not store credentials, private customer photos, or other personal data.
Agents must not generate avatar images; users provide the approved files.

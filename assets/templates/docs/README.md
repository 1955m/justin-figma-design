# Project Memory

This folder is the lightweight, traceable memory layer for the Figma
collaboration project.

## Start here

1. Read [`preferences.md`](preferences.md).
2. Read [`FILES.md`](FILES.md) to identify registered Figma files.
3. Read the latest relevant note in [`sessions/`](sessions/).
4. Read [`tools/figma-console.md`](tools/figma-console.md) before Console
   work.
5. Read the target file's living context under `files/<alias>/`.

## After meaningful design work

Create a dated note from [`sessions/_template.md`](sessions/_template.md).
Update the target `files/<alias>/design.md` and `screens.md` when authority,
components, variables, screens, root sizes, or drift changes — including any
value resolved during the session.

## Memory areas

| Area | Purpose |
|---|---|
| [`preferences.md`](preferences.md) | Stable collaboration and QA preferences |
| [`FILES.md`](FILES.md) | Figma file registry and authority |
| [`files/`](files/) | Per-file living design context |
| [`sessions/`](sessions/) | Chronological work notes |
| [`tools/`](tools/) | MCP and Desktop Bridge guidance |
| [`assets/`](assets/) | Common graphics guidance and user-provided placeholders |

Never store credentials, access tokens, private customer data, or raw
secrets in this folder.
